# AirBnb-dataset-visualization-with-Tableau
Created an interactive Tableau dashboard using the 2016 US Airbnb dataset to analyze pricing patterns, bedroom-wise averages, zipcode-level trends, and annual revenue behavior. Designed map visuals, comparative charts, and dynamic filters to reveal meaningful insights on market demand, location-based pricing, and listing distribution across regions.

Made data visualization of AirBnb dataset of year 2016 using Tableau.

Link for dataset: https://www.kaggle.com/datasets/alexanderfreberg/airbnb-listings-2016-dataset

Link of Visualization: https://public.tableau.com/app/profile/aditya.shinde8826/viz/AirBnbUSAFullProject/Dashboard1
